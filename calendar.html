Calendar — Keep Your Plans Together

Calendar is where you keep track of appointments, events and important dates — on your own, or shared with your Group.

Opening Calendar

Open the Navigation Wheel from the Planita heading and tap Calendar. You'll see a month grid with small coloured dots under any day that has Events, and below it, the list of Events for whichever day is selected. Tap Today to jump back to today, or tap the month and year heading to jump straight to a different month and year.

Creating an Event

Tap + at the top of Calendar. Fill in:

  1. Title
  2. Event Type (see below)
  3. Starts, Ends and whether it's All-day — tap the compact date summary to expand these controls, and Done to collapse them again
  4. Repeat, if it should recur (see below)
  5. Location (optional)
  6. Personal or Group — see below
  7. Attendees, for Group Events only
  8. Alert — an optional reminder notification
  9. Notes (optional)

Tap Save. A new Event you create while a Group is available starts off selected as a Group Event with you already picked as an attendee; you can switch it to Personal before saving.

Personal and Group Events

Every Event is either Personal (private to you) or belongs to your Group (visible to, and editable by, every Group Member, whoever created it). Once you've saved an Event for the first time, this choice is locked — you can't move an existing Event between Personal and Group afterwards.

For a Group Event, you also choose Attendees — either All Participants or a hand-picked Selected Participants list. Attendees just show who the Event is relevant to; they don't restrict who can see or edit it, and a Group Event needs at least one attendee selected before you can save it.

Repeating Events

Choose Repeat: Never, Every Day, Every Week, Every 2 Weeks, Every Month, Every Year, or Custom (a number of days/weeks/months/years, with specific weekdays available for a weekly custom pattern). You can also set an End Repeat date. When you edit or delete a repeating Event, you'll be asked whether the change applies to This Event, This and Future Events, or All Events.

Event Types and colours

Every Event has an Event Type (for example, General or Appointment), which gives it its colour throughout Planita. You can create, rename, recolour and disable your own Event Types from Settings → Custom Values → Event Types. A disabled type stays on any Event already using it, but can't be chosen for new Events. Personal and Group Event Types are kept completely separate.

Viewing and editing an Event

Tap an Event to open it. If you're allowed to change it, swipe it left for a quick Edit shortcut, or use Edit Event from the ⋯ menu while viewing it.

Deleting an Event

Open the Event, then use Delete Event from the ⋯ menu. For a repeating Event you'll be asked to choose This Event, This and Future Events, or All Events.

Searching your Calendar

Use the search box at the top of Calendar to find an Event by title or location. By default, search shows only upcoming matches. Tick Include past events to add historical matches to the same list.

Filtering what you see

Tap Filter to choose My Calendar (your Personal Events plus Group Events you're attending — the default), Personal, All Group, or specific Group Members.

Event History

For a Group Event, choose History from the ⋯ menu to see a simple log of who made meaningful changes and when.

Things worth knowing

  • Calendar only knows about Events created in Planita — it doesn't read from or write to your device's own Calendar app.
  • There's no RSVP, invitation or meeting-acceptance feature; attendees are informational only.
  • Past Events stay in your history unless you delete them.
